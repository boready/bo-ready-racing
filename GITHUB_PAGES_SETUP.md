# Bo Ready Racing — GitHub Pages upload

This ZIP has the website files at the repository root, including `index.html`.

1. Create or open your GitHub repository.
2. Upload the extracted contents of this ZIP to the repository root (not the ZIP itself).
3. Commit the files.
4. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`, then Save.
5. Wait for the GitHub Pages deployment and open the published site.

Note: GitHub Pages serves static files only. Server-side features from the original Node.js project (such as APIs, admin writes, and geofencing backend) are not hosted by GitHub Pages. Those need separate backend hosting.

The `videos.html` legacy link redirects to the home page video section.
